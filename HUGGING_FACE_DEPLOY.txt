TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ BUILD ERROR: "libgl1-mesa-glx not found"
───────────────────────────────────────────
FIX: Change in packages.txt:
     libgl1-mesa-glx → libgl1

❌ BUILD ERROR: "Tesseract not found"
───────────────────────────────────────────
FIX: Verify packages.txt contains:
     tesseract-ocr
     tesseract-ocr-hin
     tesseract-ocr-eng

❌ OUT OF MEMORY ERROR
───────────────────────────────────────────
This shouldn't happen (HF gives 16GB FREE)
But if it does:
- Comment out Surya OCR in ocr_engines.py
- Keep only Tesseract + EasyOCR

❌ TRANSLATION FAILS
───────────────────────────────────────────
- Wait 60 seconds (rate limit)
- Try shorter text
- Translation should work on HF Spaces

❌ APP KEEPS RESTARTING
───────────────────────────────────────────
- Check runtime.txt has: python-3.11.9
- Check packages.txt uses libgl1 (not libgl1-mesa-glx)
- View logs for specific error
