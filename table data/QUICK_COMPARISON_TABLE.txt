Key Observations:
--------------------------------------------------------------------------------
1. Image Size Scale:
   - BSTD Detection has by far the largest images (avg ~8M pixels)
   - CVIT-HW Hindi has medium-sized images (avg ~67K pixels)
   - BSTD IRSDhi has the smallest images (avg ~2.6K pixels)

2. Size Consistency:
   - BSTD IRSDhi: Most consistent (lowest std dev relative to avg)
   - CVIT-HW Hindi: Moderate consistency
   - BSTD Detection: Highly variable (std dev > avg for pixels)

3. Content Density:
   - BSTD Detection: Multiple words/lines per image (19.46 words/img)
   - BSTD IRSDhi & CVIT-HW: Single word per image (1.00 words/img)

4. Aspect Ratios (Width:Height average):
   - BSTD IRSDhi: ~1.9:1 (wider)
   - CVIT-HW Hindi: ~1.6:1 (wider)
   - BSTD Detection: ~1.3:1 (more square)

5. Dataset Scale:
   - CVIT-HW Hindi: Largest dataset (200K images)
   - BSTD IRSDhi: Medium dataset (25K images)
   - BSTD Detection: Smallest dataset (6.6K images)
